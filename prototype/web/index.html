文字元素

原文 / 译文 / 溯源可自由组合与排序，改动会立即广播给悬浮窗。

翻译

源语言、模型路径与术语保护阈值属于启动期设置，请在 config.yaml 中修改。

采集与识别

变化阈值越低越容易触发 OCR，越高越省 CPU 但可能漏掉短暂字幕。

内存档位

lean 不加载模型（约 175 MiB），balanced 常规桌面用法（约 890 MiB）。 切换档位会影响启动期配置，重启后完全生效。
