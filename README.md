# Project_Watashi
It is a project intend to build a powerful translating application on device.Real-time Translation and Custom Dictionary Libarary,supported by local LLM model.
# **摘要**

*Project:渡*

本项目是一款专注于解决网络流行语及科幻、魔幻等非现实虚构词汇翻译难题的智能辅助软件。致力于为网文出海、游戏本地化、字幕组及泛娱乐文化出海提供高效、低成本、高精度的翻译解决方案。

传统翻译工具及现有云端AI（如常规API调用）在处理“网络梗”、“网文修仙术语”或“科幻自造词”时，往往出现语义缺失、翻译生硬，甚至无法翻译的情况，导致人工译后编辑耗时费力，争议频发。

本产品通过重构人工智能翻译逻辑，在本地算法中嵌入特定翻译原则，针对虚构词汇进行自动化加工与双语转换。软件主要用于即时屏幕识别翻译，有效辅助人工翻译工作，大幅减少云端API调用成本，实现更优秀的翻译速度与数据安全。

本项目为软件工程产品，包含一套基于桌面端的“即时屏幕翻译识别工具”及配套的“自定义术语库”模块。未来可以拓展至移动端或者到更多系统架构上。

# **核心功能**

- 即时屏幕识别翻译：无需复制粘贴，悬浮窗识别屏幕文本，实现一键双语对照翻译。
- 虚构词汇自学习与翻译：针对科幻、魔幻作品，用户可设定翻译原则，系统自动对原本不存在的词语进行语义推理和自动化加工。
- 网络用语语义库：实时抓取并更新网络热梗，提供符合当代语境的翻译。
- 本地化计算：基于本地算法进行翻译处理，减少对外部API的依赖。

使用主流编程语言（C/C++、Java、Python等）设计嵌入式程序。
引入智能代码辅助工具进行代码编写，并结合人工安全检测，确保程序无漏洞、无后门，安全嵌入无冲突。
