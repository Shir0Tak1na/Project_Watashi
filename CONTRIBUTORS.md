# Contributors

Project Watashi is a graduation project. People and assistants are listed by the
work they own, not by commit count.

## Owner

  repository owner and final reviewer.

## AI assistance

- **DeepSeek** — architecture review, contract and acceptance design,
  documentation review. No repository write access; credited as a contributor,
  not a collaborator.
- **TRAE Code** — implementation assistance under owner review. Its commits carry
  `Co-authored-by: TRAE Code <trae@trae.ai>`.

## Collaborator vs contributor

- A **collaborator** has repository permission and can push. Only the owner grants it.
- A **contributor** is credited here and in the commit history. No permission is implied.
- AI assistants are not GitHub accounts: they cannot accept a collaborator invite,
  and none of them holds a token or write access to this repository.
